# Темы и Tailwind

`theme-tokens.js` — общий источник палитры для Tailwind, обычного CSS и MUI.
`themes.json` — реестр тем и их переопределений.
`App.css` подключает Tailwind и небольшие файлы совместимости в `src/styles`.
Порядок этих файлов сохраняет каскад существующих `.sw-*` и MUI-селекторов.

## Новая тема

Добавьте запись в `themes.json`: задайте `label`, `mode` и переопределите
необходимые семантические цвета в `colors`. Остальные значения наследуются
из основной палитры. Цвета задаются шестизначным HEX, например `#286b53`.
Доступны `fontFamily`, `fontScale` и `radiusScale`.

Tailwind сгенерирует переменные для `[data-theme="имя"]` при следующей сборке.
Для переключения используйте `ThemeStoreObject.setTheme('имя')` из
`src/global-theme.ts`: он обновляет тему MUI, атрибут документа и сохранённый выбор.
Неизвестная или удалённая тема заменяется темой `sage`.
Светлая тема `sage` остаётся темой по умолчанию. Кнопка палитры рядом с
«Аккаунтом» открывает выбор: Шалфей, Тёмный лес, Графит, Полночь. Она доступна
также гостям и на телефоне. «Высокий контраст» включает крупный шрифт (+30%),
увеличенные элементы управления, контрастные границы и постоянное подчёркивание ссылок.
«Высокий контраст · тёмный» использует чёрный фон, белый текст и жёлтые акценты.
Обе контрастные версии используют атрибут `data-accessibility="enhanced"`, не имя темы. Выбор сохраняется в `studyways.theme`.

Для тёмных тем переопределяйте всю палитру: малые номера оттенков используются
как тёмные подложки, большие — как светлый текст. `on-accent` — контрастный
текст залитых кнопок; в тёмных темах он тёмный. Атрибут `data-color-scheme`
объединяет стили Ant Design и CKEditor для всех тёмных тем. Цвета Chart.js
берутся из той же палитры (`chart-*`), поскольку canvas не разрешает CSS-переменные.
Тесты проверяют контраст основного текста, подписей и кнопок в тёмных темах.

## Иллюстрированные темы

`manul` («Манулья») — светлая сливочно-карамельная тема с тёмным салатовым акцентом основных кнопок.
`illustrations: "manul"` подключает набор из семнадцати иллюстраций, а
`data-illustrations` управляет оформлением. Компоненты страниц не проверяют имя темы.
`ThemeIllustration` показывает персонажей только для активного набора;
`fallback` сохраняет стандартную иконку в остальных темах. Изображения декоративные,
не перехватывают нажатия и не добавляют лишних подписей для экранного диктора.
Исходные изображения и использованные промпты находятся в `assets/manul`.

`ThemeManulNote` добавляет на страницы небольшие блоки с персонажем и цитатой.
Контекстные наборы цитат и короткие подписи для бокового меню собраны в
`manul-content.ts`. Кнопка «Ещё мысль» переключает цитаты по кругу; при смене
темы блок полностью исчезает. Новую страницу можно подключить через
`<ThemeManulNote context="library" />`. Контекст бокового меню выбирается
по пути страницы, без учёта строки поиска. Цитаты доступны экранному диктору;
картинки остаются декоративными.

## Стили компонентов

Используйте `tw-bg-surface`, `tw-text-ink`, `tw-text-secondary`,
`tw-border-border`, `tw-bg-accent`, `tw-text-on-accent` и состояния
`hover:tw-bg-accent-hover`. Прозрачность поддерживается: `tw-bg-accent/10`.
Префикс `tw-` предотвращает конфликты с Ant Design и сторонними компонентами.
Preflight отключён: сброс стилей уже выполняют MUI и Ant Design.

Размеры: `tw-p-6`, `tw-gap-4`, `tw-text-ui-14`, `tw-rounded-ui-12`.
Цвета, шкала отступов, шрифт и скругления используют CSS-переменные.
В старой разметке допустим `@apply` внутри существующего `.sw-*` селектора.
Сложные градиенты, тени и SVG-оформление остаются CSS, но используют
`var(--sw-accent)` или `rgb(var(--sw-shadow-rgb) / 0.1)` вместо HEX.

`surface`, `canvas`, `ink`, `secondary`, `border`, `accent`, `on-accent`
описывают назначение цвета. `accent-*`, `neutral-*` и статусные палитры
задают оттенки состояний. `sidebar-*` отвечают за навигацию;
`cover-*` и `art-*` — за иллюстрации каталога. Новые страницы не должны
проверять имя темы или задавать собственные HEX-цвета.

В манульем наборе также меняются названия ссылок бокового меню и текущего
раздела в верхней панели. Словарь `manulNavigation` хранится в `manul-content.ts`;
исходное назначение ссылки остаётся в подсказке и доступном имени.
Набор содержит 54 цитаты, включая шутки про механику, колебания и оптику.
